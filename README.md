# angular-lista-clientes

Lista de clientes en Angular 18 con servicio inyectable, signals y componente standalone.

> Proyecto de portafolio de Luis Felipe Zuniga Leon. Desarrollado con asistencia de IA
> (generacion de codigo, revision y documentacion); el codigo fue revisado y probado manualmente.
> No declara clientes, metricas ni resultados no verificables.

## Stack

- Angular 18
- TypeScript
- RxJS
- Signals

## Como ejecutar

```bash
npm install
npm start
```

## Estructura

```
src/app/clientes.component.ts  # componente standalone
src/app/clientes.service.ts    # estado con signals
src/app/cliente.model.ts
```

## Estado

Muestra tecnica de portafolio. Sin datos de produccion.
